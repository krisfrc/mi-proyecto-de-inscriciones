# Estudio de color — Escuela Básica Nacional La Cuadra de Bolívar

Paleta alineada con el sitio institucional [U.E. La Cuadra de Bolívar](https://pechitoxd.github.io/UE/).

## Colores institucionales

| Rol | Hex | Uso |
|-----|-----|-----|
| Azul | `#007bff` | Botones, enlaces, borde del pie |
| Azul hover | `#0056b3` | Botón al pasar el mouse |
| Azul claro | `#3498db` | Acentos secundarios |
| Dorado | `#ffd700` | Hover del menú y acentos |
| Pizarra | `#2c3e50` | Encabezado, títulos, menú lateral |
| Rojo | `#e74c3c` | Acciones críticas (borrar, rechazar) |
| Fondo | `#f8f9fa` | Página de trabajo |
| Pie | `#1a1a1a` | Footer |

## Criterio

- El **azul Bootstrap** (`#007bff`) es el color de acción, igual que en la web de la escuela.
- El **dorado** marca el hover de la navegación.
- El **encabezado oscuro** (`#2c3e50`) replica el overlay de la portada institucional.
- El **rojo** solo para acciones irreversibles.
- Las grillas usan blanco y fila seleccionada en azul claro `#d6ebff`.

No se dejan selectores de color en la interfaz: la paleta queda fija para la institución.
